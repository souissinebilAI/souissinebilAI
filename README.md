### Projects

**[ArtikelFinder](https://github.com/souissinebilAI/ArtikelFinder)**: browser extension that shows
*der / die / das* for any selected German noun, including inflected forms. Built from UniMorph and
Wikidata; profiling the sources found and fixed wrong genders and missing nouns. Runs fully offline.

**[ai-it-support](https://github.com/souissinebilAI/ai-it-support)**: IT service desk in Power Apps
and Dataverse. A Microsoft Foundry agent suggests category and priority for each ticket; the user
can always override the suggestion.

**[wohinder](https://github.com/newfreshhorizonx/wohinder)** (team of two): iPhone-optimized swipe app
(PWA) for apartment hunting in Darmstadt. My part: extending the FastAPI backend, the offline-capable
HTML/CSS/JS frontend, 23 automated tests, and a Git workflow with pull requests.

**[crypto-daily-report](https://github.com/souissinebilAI/crypto-daily-report)**: a GitHub Actions
workflow that fetches market data every morning and commits a report with a 7-day chart.
Its daily commits are automated and labelled `chore(bot)`.
